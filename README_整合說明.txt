# 新暮光森林 v2.7.4｜Excel 整合版

本版本以原始網站為基礎，已匯入「新暮光之晨攻略表 (製作中).xlsx」所有工作表的原始資料。

## 使用方式
1. 用 VS Code 開啟此資料夾。
2. 使用 Live Server 開啟 `index.html`。
3. 完整 Excel 資料瀏覽器位於：
   `pages/攻略資料庫.html`

## 資料
- `data/excel_data.json`：Excel 所有工作表的原始資料。
- 原網站 `index.html / style.css / app.js` 保留。
- 後續可再把 Excel 資料進一步正規化成「職業、裝備、材料、NPC、技能、IMP、合成/前置」等真正的互動資料庫。
